Ультра-легковесное, аппаратное оптимизированное веб-приложение для мастеров настольных ролевых игр (D&D, Pathfinder). Разработано по двухоконной модели: **Панель Мастера (DM View)** для управления картой и туманом войны + **Экран Игроков (Player View)** для вывода на второй монитор, проектор или ТВ.

Оптимизировано для работы на любых системах, включая винтажное и слабое железо (MacBook Air 2010 с 2 ГБ ОЗУ, процессором Core 2 Duo и GeForce 320M, а также любые современные ПК под Windows, macOS и Linux).

## 🚀 Скачивание и запуск из GitHub Releases

Каждый коммит в ветку `main` автоматически собирается и публикуется на вкладке **[Releases](https://github.com/)** вашего репозитория.

В каждом релизе доступны готовые файлы для скачивания:

| Файл в релизе | Для кого / Назначение | Как запустить |
|---|---|---|
| **`dnd-projector-standalone.html`** | 🌟 **Универсальный (Win / Mac / Linux)**. Один файл, **0 зависимостей**. Не требует установки Node.js или интернета. | Просто дважды кликните по файлу или откройте в любом браузере (Chrome, Safari, Firefox, Edge). |
| **`dnd-projector-offline-all-os.zip`** | Архив с автономной версией + удобными скриптами быстрого запуска под Windows, macOS и Linux. | Распакуйте архив и запустите нужный файл для вашей ОС (см. ниже). |
| **`dnd-projector-nextjs-server.zip`** | Полная сборка с сервером Next.js и лаунчерами. | Распакуйте архив и запустите `start-windows.bat`, `start-macos.command` или `start-linux.sh`. |

## 💻 Инструкции по запуску для платформ

### 🪟 Windows
1. Скачайте `dnd-projector-offline-all-os.zip` или `dnd-projector-standalone.html` со страницы **Releases**.
2. Если скачали архив — распакуйте его в любую папку.
3. Дважды кликните на **`start-windows.bat`** (скрипт сам откроет браузер) или просто дважды кликните на **`standalone.html`**.

### 🍎 macOS
1. Скачайте `dnd-projector-offline-all-os.zip` или `dnd-projector-standalone.html`.
2. Распакуйте архив.
3. Дважды кликните на **`start-macos.command`** (или дважды кликните на **`standalone.html`** для открытия в Safari / Chrome).
   *(При первом запуске `.command` файла macOS может запросить подтверждение прав: в Терминале можно выполнить `chmod +x start-macos.command`)*.

### 🐧 Linux
1. Скачайте архив или html-файл.
2. Распакуйте архив.
3. Запустите в терминале:
   ```bash
   chmod +x start-linux.sh
   ./start-linux.sh
   ```
   или просто откройте `standalone.html` в браузере: `xdg-open standalone.html`.

## ⚙️ Автоматизация GitHub Actions (CI/CD)

В репозиторий встроен рабочий процесс `.github/workflows/release.yml`, который:
1. Автоматически запускается **при каждом push / коммите в ветку `main`** (а также при создании тегов `v*`).
2. Собирает продакшн-версию и упаковывает автономные бандлы под все платформы.
3. Создает новый **GitHub Release** с тегом `v1.0.<номер_сборки>` и прикрепляет к нему все готовые zip-архивы и standalone HTML файл.
4. Вы можете также запустить релиз вручную на вкладке **Actions** -> **Automated GitHub Release** -> **Run workflow**.

## 🛠️ Разработка и локальная сборка

Если вы хотите запустить проект в режиме разработки или собрать релиз вручную:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки
npm run dev

# 3. Сборка проекта
npm run build

# 4. Упаковка релизных артефактов в папку release-artifacts/
npm run package:release

# 5. Запуск локального статического сервера
npm run serve:local
```

## 🎮 Горячие клавиши и управление

- **`R`**: Инструмент «Открыть туман» (Reveal Brush)
- **`H`**: Инструмент «Скрыть туман» (Hide Brush)
- **`M`**: Линейка измерений расстояния (Ruler в футах и клетках)
- **`P`**: Инструмент панорамирования (Pan)
- **`Space` + Перетаскивание мышью**: Быстрое перемещение по карте
- **`Alt` + Клик**: Лазерная указка / пинг на экран игроков
- **Колесико мыши**: Плавный зум
- **`F`** (в окне игроков): Полноэкранный режим на проекторе

## 🛡️ Архитектурные особенности
- **Синхронизация через `BroadcastChannel API`**: Мгновенный обмен данными между окнами мастера и проектора на одном компьютере без задержек сети и без тяжелых веб-сокетов.
- **Векторный протокол тумана**: Передаются только действия кисти, а не мегабайты графики.
- **Нулевые утечки памяти**: Автоматический вызов `URL.revokeObjectURL()` при смене медиафайлов.
